# Soal 1 (45 Menit)

Buatlah sebuah program yang bertujuan untuk mencatat **data katalog musisi** menggunakan **record (struct)**, memanfaatkan **pointer** agar ukuran array lebih fleksibel, serta menggunakan **file operation** agar data tetap tersimpan secara permanen.

Program ini memungkinkan pengguna untuk:

- Menambahkan data musisi baru.
- Menampilkan semua data musisi beserta total album terjual dan total album yang telah dirilis.
- Menampilkan **rata-rata penjualan per album** (Penjualan/Album) untuk setiap musisi.
- Menyimpan dan membaca data dari file, sehingga informasi katalog musisi tetap tersedia meskipun program ditutup.

---

### Data yang disimpan:

- Nama Musisi
- Genre Musik
- Jumlah Album Terjual
- Jumlah Album Dirilis
- (mau tambahin yang lain bole)

---

### Tampilan Menu: (Bisa disesuaikan selera)

1.  Tambah Musisi
2.  Tampilkan Semua Musisi
3.  Tampilkan Rata-rata Penjualan/Album setiap musisi
4.  Keluar
